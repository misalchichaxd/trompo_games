# 🎮 el trompo · Menú de Juegos

> Interactivo de juegos del **Museo Interactivo Tijuana**  
> Elige una aventura, aprende jugando y supera tu récord.

## 🕹️ Juegos incluidos

| Juego | Descripción | Tecnología |
|-------|-------------|------------|
| **🤖 Trompobot** | Laberinto de ciencia tipo Pac-Man. Recoge chispas, evita triángulos y usa el dash. | HTML5 Canvas 2D |
| **🧊 Cube Runner** | Corre en 3 carriles, salta obstáculos y junta monedas en una pista 3D. | Three.js |

## 🚀 Cómo jugar / probar

Abre `index.html` o sirve la carpeta:

```bash
python -m http.server 8000
# o
npx serve .
